# CLAUDE.md

Этот файл — контекст для Claude Code при работе с репозиторием `cleanservice24`.
Заполни разделы ниже по мере развития проекта; лишнее — удаляй.

## О проекте

Рабочее пространство для подготовки рекламы в Яндекс.Директ для клининговой компании.

Модель работы:
- Вся реклама ведётся **одной рекламной кампанией**. Каталог `yadirect/` — это набор её **групп объявлений**.
- Настройки самой кампании (стратегия, бюджет, расписание, геотаргетинг, ставки и т. п.) здесь **не рассматриваем**.
  Работаем только с группами: ключевые фразы, минус-слова, объявления, посадочные страницы.
- Группы объединены по **направлениям** клининга. Каждое направление — подкаталог в `yadirect/`,
  внутри которого может быть несколько групп (например, по типу объекта).

## Структура каталогов

- `yadirect/` — группы единой рекламной кампании Яндекс.Директ, разложенные по направлениям
  - `yadirect/мытье окон/` — направление «Мытьё окон» (группы — по мере проработки)
  - `yadirect/после ремонта/` — направление «Уборка после ремонта» (проработаны группы «Уборка после ремонта общие», «Дом/коттедж после ремонта» и «Квартиры после ремонта»)
    - `ads.md` — комбинаторные объявления К1–К3 (раздел `## 1. уборка после ремонта общие`)
    - `уборка после ремонта общие/keyword.txt` — ключевые фразы группы с частотой («База»)
    - выгрузки Директа и скрипты для этого направления отдельно не ведём — они в `yadirect/клининговые услуги/import/` и `scripts/` (кампания одна)
  - `yadirect/<направление>/` — по мере добавления новых направлений клининга
- `.claude/skills/` — кастомные skills для Claude Code
- `.claude/agents/` — кастомные subagent'ы для Claude Code

Правило раскладки (как в `клининговые услуги/` и `после ремонта/`): каждая группа — отдельный подкаталог направления
(`yadirect/<направление>/<группа>/`) с файлом ключевых фраз (`keywords.txt` / `keyword.txt`, колонка «База» — частотность);
объявления всех групп направления — в одном `yadirect/<направление>/ads.md`, по разделу `## N. <группа>` на группу;
общее для направления (минус-слова, отчёты) лежит уровнем выше. Выгрузки Директа и скрипты — в `yadirect/клининговые услуги/import/` и `scripts/` (кампания одна).

| Элемент | Лимит |
|---|---|
| Заголовок | 56 знаков (включая пробелы и знаки препинания); одно слово — не более 22 символов |
| Дополнительный заголовок | 30 знаков и 15 знаков препинания; одно слово — не более 22 знаков |

### Правила составления объявлений в `yadirect/клининговые услуги/`

Относится к файлу `yadirect/клининговые услуги/ads.md`. Яндекс.Директ теперь принимает только **комбинаторные** объявления: в одном объявлении задаётся 7 заголовков и 3 текста, Яндекс сам тестирует их сочетания.
Источник ключевых фраз — `<раздел>/keywords.txt` (колонка «База» — частотность).

**Схема раздела (`## N. <фраза>`)** — три комбинаторных объявления `К1`, `К2`, `К3`, у каждого 7 заголовков и 3 текста:
- Уже написанные ранее объявления (`N.1`–`N.5`, `2.6`–`2.13` и т. п.) НЕ удаляем и не переписываем; новые объявления добавляются после них, отделяются строкой `★ ★ ★ … ★ ★ ★`.
- Доп. заголовок и отображаемую ссылку в комбинаторных объявлениях не указываем.
- Заголовок ≤56 знаков, слово ≤22; текст ≤81 знака и ≤15 знаков препинания, слово ≤23. Лимиты проверяем скриптом, а не на глаз.
- Любой заголовок может показаться с любым текстом: каждый заголовок и текст должны быть понятны сами по себе, не повторять друг друга и не противоречить друг другу.
- Цены в объявлениях не указываем (допустимо «узнайте стоимость по звонку»). Не обещаем того, чего нет на сайте (гарантии, сроки выезда, «срочно», переуборка, страховка).
- Регион в текстах не указываем, пока он не подтверждён владельцем для данного направления; региональные ключи (Тула, Подольск и т. п.) в заголовки не берём.

**К1 — по сайту и УТП**
- Основа — УТП с сайта: без предоплат, бесплатная консультация, свои химия, инвентарь, лестницы и пылесосы, постоянный коллектив, срок зависит от площади и загрязнённости.

**К2 — по ключам с наибольшей частотой**
- Заголовки строим из самых частотных фраз `keywords.txt` раздела (колонка «База»), в начале заголовка; совпадающая с запросом часть выделяется жирным и повышает CTR. Разные заголовки — разные частотные фразы; не перегружать ключами.
- Тексты нейтральные, с призывом к действию, подходят к любому заголовку (в т. ч. к «квартиры» и «офис»).

**К3 — по анализу эффективных объявлений в сети**
- Уходим от УТП сайта: выгода клиента (свободное время, порядок к возвращению, чистый офис для команды), вопрос-триггер («Устали от уборки?»), конкретная картинка результата.
- Текст не повторяет заголовок, а добавляет аргумент и заканчивается призывом к действию (позвоните, оставьте заявку).
- Заголовки грамотные и развёрнутые, без телеграфного стиля; без частицы «не», кликбейта, капслока и общих слов без смысла.
- Объект (квартиры, офисы) выносим в заголовок, только если он соответствует ключевой фразе раздела.

Источники рекомендаций: справка Яндекс Директа «Заголовок и текст», материалы eLama, SV Digital, блог Д. Ржанского.
Эффективность вариантов оцениваем по конверсии в заявку, а не только по CTR; для выводов нужно минимум ~14 дней и ~100 кликов на вариант.
Статус: схема применена к разделам «клининг», «клининговая компания», «клининг услуги», «заказать уборку и клининг» (в него влит раздел «заказать клининг» — отдельной группы нет), «клининг уборка» (в К2 по решению владельца оставлены города Серпухов и Подольск) «услуги уборки» и «клининговые услуги» (в К2 оставлен Серпухов; Протвино в ключах нет); остальные разделы (клининговая служба, генеральная уборка) переводим поэтапно по запросу владельца. Направление «Уборка после ремонта» ведётся по той же схеме К1–К3, но отдельно — в `yadirect/после ремонта/ads.md`.
Выгрузка Директа (`import/`): рабочая — `716527410_v11.xls` = свежая выгрузка `716527410_fresh.xls` (25.11.2026, 15:34; группы 1–11 с ID, в т. ч. 11 «Клининг уборка квартир») + новые группы 12 «Уборка квартир общие» и 13 «Сколько стоит уборка квартиры» (без ID, их присвоит Директ; посадочная — `/uborka-kvartir/`). Файлы `_v2`–`_v10` не загружать — они устарели: у групп, уже созданных в Директе, в них нет ID, будут дубли. Новые группы добавляет `scripts/add_group.py` (по образцу группы «Клининговые услуги»; результат пишет в новый файл; параметры `--ads`, `--kwfile`, `--url`, `--region`, `--exclude`, `--template` позволяют брать объявления и ключи из других каталогов, менять посадочную и исключать фразы). Правила: `fresh` руками и скриптом не дополняем — это снимок Директа, и строки без ID, добавленные в него, при повторной загрузке создадут дубли; основа для новой группы — `fresh` плюс ещё не загруженные группы без ID (последний `_vN`). Сообщение Директа «отсутствуют группы» значит, что в файле нет уже существующей в Директе группы: тогда нужна новая выгрузка. После каждой загрузки в Директ — выгружать кампанию заново и класть как `fresh`.
