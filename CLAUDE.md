Этот файл — контекст для Claude Code при работе с репозиторием `cleanservice24`.
Заполни разделы ниже по мере развития проекта; лишнее — удаляй.

## О проекте

Рабочее пространство для подготовки рекламы в Яндекс.Директ для клининговой компании.

Модель работы:
- Вся реклама ведётся **одной рекламной кампанией**. Каталог `yadirect/` — это набор её **групп объявлений**.
- Настройки самой кампании (стратегия, бюджет, расписание, геотаргетинг, ставки и т. п.) здесь **не рассматриваем**.
  Работаем только с группами: ключевые фразы, минус-слова, объявления, посадочные страницы.
- Группы объединены по **направлениям** клининга. Каждое направление — подкаталог в `yadirect/`,
  внутри которого может быть несколько групп (например, по типу объекта).

## Площадка

## Структура каталогов

- `yadirect/` — группы единой рекламной кампании Яндекс.Директ, разложенные по направлениям
  - `yadirect/okna/` — направление «Мытьё окон» (группы — по мере проработки)
  - `yadirect/after_renovation/` — направление «Уборка после ремонта» (4 группы, см. ниже)
    - `general/`, `cottages/`, `apartments/`, `offices/` — группы; в каждой `keywords.md`, `ads.md`, `minus_words.md`
    - `minus_words.md` — общие минус-слова направления; `keywords_freq.md`, `wordstat.py` — частоты Wordstat
  - `yadirect/<направление>/` — по мере добавления новых направлений клининга
- `.claude/skills/` — кастомные skills для Claude Code
- `.claude/agents/` — кастомные subagent'ы для Claude Code

Правило раскладки: каждая группа — отдельный подкаталог направления (`yadirect/<направление>/<группа>/`)
с файлами `keywords.md`, `ads.md`, `minus_words.md`; общее для всех групп направления (общие минус-слова, отчёты) лежит уровнем выше.

## Направление "Мытье окон"
Рабочий каталог cleanservice24/yadirect/okna
В объявлениях нужно оразить услуги по мытью окон в коттеджах, загородных домах, мытье окон и лоджий в квартирах. 
И делаем упор на мытье окон в коттеджных посёлках. 

## Направление "Уборка после ремонта"
Рабочий каталог cleanservice24/yadirect/after_renovation
Посадочная страница: https://cleanservice24.ru/uborka-posle-remonta/
Объекты: коттеджи, деревянные дома, квартиры, офисы (другие коммерческие объекты — магазины, склады, производства, медучреждения — не заявлены и вынесены в минус-слова).
Группы направления (все — группы одной кампании): 1 — общий случай (`general/`), 2 — коттеджи и дома (`cottages/`), 3 — квартиры (`apartments/`), 4 — офисы (`offices/`). Частоты — `keywords_freq.md` (собирается скриптом `wordstat.py` через XMLRiver; ключ API — в переменных окружения `XMLRIVER_USER` и `XMLRIVER_KEY`, в репозиторий не коммитить).
Регион работы: Москва и Подмосковье (подтверждено владельцем; на сайте не указан, поэтому в текстах объявлений регион не упоминаем; сам геотаргетинг — настройка кампании, вне рамок этого репозитория).
Акцент на конкретном типе объектов пока не делаем — все объекты равнозначны.
Цены в объявлениях НЕ указываем.

УТП с сайта (брать за основу объявлений):
- устранение строительных загрязнений, удаление затирок и герметиков;
- обеспыливание стен от пола до потолка;
- мытьё окон со следами лаков и красок;
- лестницы, пылесосы, химию и инвентарь привозит компания;
- без предоплат, бесплатная консультация;
- постоянный коллектив, срок зависит от площади и загрязнённости.

Цены с сайта (только для справки, в объявления не выносить):
- коттеджи: до 130 м² — 16 900 ₽, до 150 — 19 500, до 170 — 22 100, до 200 — 26 000, свыше 200 — договорная;
- деревянный дом: 140 ₽/м²;
- квартиры без мебели: от 10 000 ₽ (до 50 м²); с мебелью: от 12 000 ₽ (до 50 м²);
- офисы: цен на сайте нет (уточнить у владельца).

Нет на сайте (не обещать в объявлениях): зоны обслуживания, формальные гарантии, условия страхования.

## Конвенции

### Ограничения символов в объявлениях Яндекс.Директ

Единые для всего проекта — действуют во всех подкаталогах `yadirect/<направление>/`.

| Элемент | Лимит |
|---|---|
| Заголовок | 56 знаков (включая пробелы и знаки препинания); одно слово — не более 22 символов |
| Дополнительный заголовок | 30 знаков и 15 знаков препинания; одно слово — не более 22 знаков |
| Текст объявления | 81 знак и 15 знаков препинания; одно слово — не более 23 знаков (текст может обрезаться в зависимости от места показа) |
| Ссылка | 1024 знака (включая протокол) |
| Отображаемая ссылка | 20 знаков (не считая домен) |
| Уточнения | 25 знаков с учётом пробелов; суммарная длина уточнений на объявление — не более 132 знаков на десктопах и не более 76 на мобильных |
| Быстрая ссылка — заголовок | 30 знаков |
| Быстрая ссылка — описание | не более 60 знаков |
