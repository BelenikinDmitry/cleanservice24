# import/ — данные для ручного переноса в Яндекс.Директ

Файлы собраны из `<группа>/keywords.md`, `<группа>/ads.md`, `<группа>/minus_words.md` и `../minus_words.md`.
CSV: кодировка UTF-8 с BOM, разделитель `;` (открываются в Excel). Это **производные файлы** — править нужно исходные `.md`, затем пересобирать.

| Файл | Что внутри |
|---|---|
| `1_groups.csv` | 4 группы: название, регион, минус-слова группы одной строкой в формате `-слово -слово` |
| `2_keywords.csv` | 159 ключевых фраз с номером группы и частотой (частота — справочно) |
| `3_ads.csv` | 20 объявлений: заголовки, текст, ссылка, отображаемая ссылка, уточнения через ` \|\| ` |
| `4_common_minus_campaign.txt` | общие минус-слова (121 строка) — на уровень кампании |

Названия колонок — рабочие, не официальный шаблон Директа. Если интерфейс Директа требует свой шаблон,
скачайте его из Директа и перенесите колонки (соответствие очевидное) либо пришлите шаблон — адаптирую.

Что учесть при переносе:
- Фразы в `2_keywords.csv` — без операторов («!», «+», кавычки): добавляйте при необходимости в Директе.
- В `4_common_minus_campaign.txt` есть строка из двух слов («своими руками») — вставляйте как словосочетание.
- Минус-слова группы 2 включают «лоджия» и «балкон» — см. пояснение в `cottages/minus_words.md`.
- Быстрые ссылки не подготовлены.
