# yadirect/after_renovation/

Направление «Уборка после ремонта». Это набор **групп объявлений** единой рекламной кампании Яндекс.Директ;
настройки самой кампании здесь не рассматриваются. Правила и конвенции проекта — в корневом [CLAUDE.md](../../CLAUDE.md).

Посадочная страница: https://cleanservice24.ru/uborka-posle-remonta/

## Группы

Каждая группа — отдельный подкаталог с тремя файлами: `keywords.md` (ключи с частотами), `ads.md` (объявления), `minus_words.md` (минусы, разводящие группу с остальными).

| Группа | Каталог | Ключей | Объявления |
|---|---|---|---|
| 1. Общий случай | [general/](general/) | 86 | 1.1–1.5 |
| 2. Коттеджи и дома | [cottages/](cottages/) | 18 | 2.1–2.5 |
| 3. Квартиры | [apartments/](apartments/) | 45 | 3.1–3.5 |
| 4. Офисы | [offices/](offices/) | 10 | 4.1–4.5 |

Всего 159 ключевых фраз.

## Общие файлы направления

- [minus_words.md](minus_words.md) — общие минус-слова на все группы направления.
- [keywords_freq.md](keywords_freq.md) — отчёт по частотам XMLRiver Wordstat (вся Россия, все устройства), включая отброшенные нулевые фразы и новые фразы из выдачи.
- [wordstat.py](wordstat.py) — скрипт сбора частот. Ключ API берётся из переменных окружения `XMLRIVER_USER` и `XMLRIVER_KEY` (в репозиторий не коммитить). Результат пишет в `keywords_freq_update.md`, исходный отчёт не перезаписывает. Сырые ответы кэшируются в `/tmp/wordstat_raw`.

## Заметки

- Ключи отобраны по частотам: убраны все 143 фразы с нулевой частотой, бренды конкурентов, покупка химии, вывоз мусора, подъезды, другие города.
- «Клининг частного дома» (104) и «клининг загородного дома» (75) могут включать регулярную уборку — следить за поисковыми запросами и при необходимости добавлять минусы.
- Офисы — целевой объект; другие коммерческие (магазины, склады, производства, медучреждения) — в минус-словах.
- Группа «Офисы» небольшая по трафику (~180 показов в месяц) — можно начать с одного объявления.
- Фразы с частотой 1–10 оставлены только в группах 2–4, ставки на них на старте не поднимать.
